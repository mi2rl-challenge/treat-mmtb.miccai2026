# TREAT-MMTB 2026

**MICCAI 2026 Challenge on AI-driven Cavity Segmentation and TB Classification**

🌐 Website: https://treat-mmtb.mi2rl.co/

## About
Tuberculosis remains a critical global health challenge, yet manual CXR assessment is slow, subjective, and limited by the shortage of trained radiologists. This challenge introduces two tasks to address these gaps: cavity segmentation on chest X-rays and TB classification integrating imaging with clinical metadata — built on multi-center data from multiple countries to ensure clinical generalizability.


## Tasks

Each task includes a baseline notebook with preprocessing, model training, and evaluation examples for reference.

- **Task 1: Cavity Detection & Segmentation** → `Task1/task1_explain_baseline.ipynb`
- **Task 2: TB Classification** → `Task2/task2_explain_baseline.ipynb`
